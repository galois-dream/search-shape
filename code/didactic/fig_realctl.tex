% fig_realctl.tex -- One question per panel: how much does the ACTUAL arrangement of a query's neighbours
% add, beyond the corpus-bearing control (same cosines, bearings borrowed from random chunks of the corpus)? x = real
% minus control AUROC (fixed 250-token queries, size-matched C250 vs C750, own document left out), dot = one embedding
% model, bar = paired document-bootstrap 95% interval (data/reference_outputs/bayes/bb_cells_subvar.csv). Vermillion = clear by the
% registered rule (interval above 0 and real AUROC above 0.5). Corpora are bands; models are stacked inside each band
% in a fixed order (listed in the caption; the numbers are in the supplementary table). Data: data/realctl.dat and
% data/realctl_meta.tex from code/paper_tables/make_real_tables.py. \input from main.tex.
